# Dependencies
- go

# Run API
1. make sure you have installed all dependencies
2. run `export MONGODB_URI="mongodb+srv://<user>:<password>@cluster0.izzvd.mongodb.net/?retryWrites=true&w=majority&appName=Cluster0"`
3. run `go get abigo` this will check and install all modules that this project needs
4. run `go run main.go`
